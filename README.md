# GCP Cloud Security Engineering

A hands-on project exploring security engineering in Google Cloud through infrastructure as code, automation, and secure delivery.

This repository will showcase working implementations with code, design decisions, and evidence of how they were tested.

## Project status

Initial repository setup is complete. The first Terraform implementation is in development; no cloud infrastructure has been deployed yet.

As implementations are completed and verified, this README will link to their code, architecture, and results.
